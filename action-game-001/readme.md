# 《余烬航线》游戏企划

> 暂定名。一个竖版 2D 飞机射击游戏：贴着弹幕飞来积攒能量，再用一次精准冲刺把危险转成火力。

## 项目概况

- **类型：** 竖版卷轴射击（shmup）＋轻量 Roguelite
- **平台：** Windows PC；优先键盘，预留手柄支持
- **引擎：** Godot 4.7（当前项目配置）
- **单局时长目标：** 10–15 分钟
- **目标玩家：** 喜欢街机射击、弹幕躲避和短局构筑的玩家；难度从新手可上手到熟练后追求高分
- **开发规模：** 先做单人可完成的垂直切片，不以大量关卡和美术资产为前提

## 一句话卖点

在一片正在坍缩的天空里，驾驶小型拦截机穿过敌方弹幕。擦弹会充能；满能后可以沿瞄准方向“折跃”，清除路径上的弹幕并引爆敌机。玩家要决定是稳妥地远离危险，还是贴近弹幕换取反击机会。

## 设计支柱

1. **躲避读得懂：** 敌弹按颜色和形状区分行为，危险区有明确预告，背景不与弹幕抢对比度。
2. **攻击与躲避连在一起：** 擦弹不是纯粹加分，而是为折跃反击充能；贴近风险能换来主动进攻资源。
3. **每局有构筑选择：** 关卡间选择武器模块和航线，组合改变攻击方式，而不是只把伤害数字越堆越大。
4. **短局、可重开：** 每段遭遇控制在几分钟内，失败后能很快再次出击；操作手感和可读性优先于内容数量。

## 核心循环

```text
进入航段 → 躲避并攻击敌机 → 擦弹充能 / 收集残骸 → 击破精英或头目
    → 选择模块与下一条航线 → 迎战更复杂的弹幕 → 击败关底头目或返航结算
```

### 操作草案

| 操作 | 键盘默认 | 作用 |
|---|---|---|
| 移动 | WASD / 方向键 | 八方向移动；飞船不超出战斗区域 |
| 主武器 | 按住 J / Space | 持续射击，早期不要求玩家反复点按 |
| 低速精控 | 按住 Shift | 降低移动速度并显示较小的受击核心，方便穿越弹幕 |
| 折跃冲刺 | 按 K | 消耗满格擦弹能量，短距离冲刺并清除路径上的普通敌弹 |
| 暂停 | Esc | 暂停、继续或返回标题画面 |

移动、射击、精控与冲刺按键都应支持重映射。低速模式下显示碰撞核心，碰撞判定明显小于飞船外观。

## 关键机制

### 擦弹与折跃

- 玩家靠近敌弹但没有碰撞时获得擦弹值；连续擦弹会有短暂倍率，鼓励沿弹幕边缘移动。
- 能量满格后可以折跃。默认沿当前移动方向冲刺；静止时朝机头前方冲刺。
- 冲刺路径上的普通敌弹被清除；路径上的敌机受到伤害。头目弹幕不被直接清除，避免核心战斗被一键跳过。
- 擦弹奖励有上限和短暂冷却，避免原地贴弹刷资源。

这条机制是项目的主要辨识点。第一版先验证“擦弹充能 → 冲刺反击”是否好懂、好控、值得冒险，再扩充武器和关卡。

### 武器与构筑

每个遭遇结束后给出三个模块供玩家选一个。首个可玩版本只做六种模块：

- **裂光炮：** 主炮伤害提高，射速略降。
- **双联翼炮：** 增加两侧副射，覆盖更宽。
- **追踪蜂群：** 定期发射追踪小弹，适合处理边缘敌人。
- **残骸磁吸：** 更容易收集残骸，冲刺距离略短。
- **过载回路：** 擦弹充能增加，折跃伤害降低。
- **余烬护盾：** 每段航程首次受击时抵消伤害，之后失效。

模块以改变决策和弹道为主，少放纯数值升级。模块组合要避免出现唯一最优解。

### 航线选择

头目战之间提供两个可选航段：

- **补给线：** 敌人较少，可修复少量装甲或获得模块重选机会。
- **风暴线：** 弹幕更密，奖励更多残骸或一件稀有模块。

第一版只需要两类航段，不做复杂地图生成；通过固定节点和少量随机排列获得重玩变化。

## 世界与美术方向

太阳熄灭后的近地轨道，人类舰队靠回收旧卫星维持能源。玩家是护送回收船的轻型战机，在每次任务中争取带回足够的“余烬”燃料。

- 采用清晰的低分辨率像素风或简化矢量风，最终风格等有占位原型后再锁定。
- 舰船以醒目的轮廓和少量高亮色表现；敌弹颜色与玩家弹、掉落物严格区分。
- 背景用暗色星空、稀疏残骸和缓慢视差，关键战斗区域保持干净。
- 头目按阶段改变轮廓和弹幕节奏，血条旁显示阶段提示。
- 爆炸、命中闪烁和冲刺残影负责提供打击感；屏幕震动与闪光都提供关闭选项。

## 首个可玩版本（MVP）

目标是做出一局完整、能反复玩的 10 分钟原型：

- 标题画面、开始、暂停、失败与结算界面
- 一艘玩家战机、一种主炮、一种折跃能力
- 三种普通敌机、一个精英敌机、一个有三个阶段的关底头目
- 两种航段模板和六种模块
- 固定关卡节奏，敌群位置允许轻度随机变化
- 生命、擦弹能量、分数、模块提示和头目血条 UI
- 音效占位、基础音乐、键盘操作与手柄基本支持
- 一轮任务约 10 分钟，能从标题画面进入并完成完整结算

**暂不纳入首版：** 联机、排行榜服务器、剧情分支、大型永久升级树、程序化弹幕编辑器、多角色、多章节和高密度全屏弹幕。先把移动、命中反馈和一场头目战做扎实。

## 难度与可访问性

- 提供「巡航」与「王牌」两个难度；巡航降低敌弹速度和弹量，并增加一次容错，不改变核心机制。
- 提供按键重映射、屏幕震动开关、闪光强度选项和音量独立控制。
- 弹幕同时用形状、运动方式和颜色传达危险，不单靠颜色区分。
- 玩家受击后有短暂无敌时间，并通过明显闪烁提示；危险弹幕出现前给足反应时间。
- 结算展示命中、擦弹、折跃击破和航段选择，让玩家知道表现如何提升。

## Godot 实现建议

- `Node2D` 作为战斗场景根节点；玩家使用 `CharacterBody2D` 或 `Area2D` 实现移动和碰撞。
- 玩家受击核心与可视飞船分开：单独的 `Area2D` / `CollisionShape2D` 负责受击判定。
- 子弹和敌机做成独立场景，通过 `PackedScene` 生成；需要时用对象池减少大量弹幕的创建开销。
- `Resource` 定义武器、敌机、模块和弹幕参数，尽量把调数值与脚本逻辑分开。
- 敌人攻击使用小型状态机与计时器；先用可复用的直线、扇形、瞄准、环形弹幕组合。
- 关卡节奏写成数据资源或波次脚本，原型阶段保持固定，方便调难度与复现问题。
- 输入统一走 Input Map；窗口拉伸按当前项目的 `canvas_items` 设置继续验证。

## MVP 原型状态

当前原型已把完整的开始、战斗、模块选择、补给 / 风暴航线选择、旗舰战、胜负结算串起来。为了先验证核心机制，原型将企划中的 10–15 分钟单局压缩为约 2–3 分钟的一条航线；之后再扩展到多个航段和更完整的任务长度。画面暂用程序绘制的几何占位图形。

运行方式：用 Godot 4.7 打开本目录的 `project.godot`，运行主场景。标题画面按 Enter 或 Space 开始；战斗中按 Esc 暂停，胜负后按 Enter 或 Space 重开。

原型操作：WASD / 方向键移动，按住 Shift 低速精控，按住 Space 或 J 射击，K 或 X 在擦弹能量满时折跃，升级画面按 1 / 2 / 3 选择模块，航线画面按 1 / 2 选择补给线或风暴线。

## 下一阶段：局外成长与失败后选择

玩家反馈希望 Roguelite 循环在 Game Over 后仍能提供长期成长，并允许玩家自己决定是回机库整备还是就地再挑战。后续按以下方向设计，当前尚未实现：

- **任务奖励货币：** 每次出击根据分数、击破头目和任务进度结算“余烬”；失败也能带回已获得的奖励，避免失败一无所获。结算需防止同一局重复领奖。
- **机库商店：** 回主页面 / 机库后用余烬购买装备和永久强化。优先提供有取舍的侧向解锁和小幅便利提升，避免永久数值成长压过飞行与躲弹技巧。
- **Game Over 双选项：**「返回机库」结算奖励并进入商店 / 装备界面；「从本航段开始重试」回到该航段起点，恢复进入航段时的生命、局内模块和敌人状态，保留本次出击开始前已装备的机库装备。
- **航段检查点：** 进入每条航段时保存可重试状态快照。重复挑战同一航段不重复结算此前已领取的奖励；若玩家返回机库并开始新出击，则从第一航段重新开始。

下一步实现建议：先加持久化的货币与装备存档、Game Over 奖励结算和两个按钮；再加入航段开始快照与重试；最后搭建机库商店 UI，并验证退出重开后数据仍正确保存。

## 开发顺序

1. **手感原型：** 玩家移动、低速精控、主炮、单种敌人和可测试的碰撞核心。
2. **机制验证：** 加擦弹充能和折跃，确认读得懂、操作可靠、风险回报明显。
3. **一场完整战斗：** 加入普通波次、精英敌、头目三阶段、血量与胜负流程。
4. **重玩循环：** 加模块选择、两条航线、分数结算和再次开始。
5. **打磨：** 改善弹幕区分、特效、音效、难度选项与手柄支持。

每个阶段结束时都应能直接运行并体验，不等所有资源完成后才首次试玩。

## 研究观察与设计取舍

近期作品和评论显示，射击游戏仍有几条可借鉴的路线：

- **传统街机射击仍靠清晰的核心操作取胜。** 2025 年的《Exo-Calibre》评论强调，短流程、鲜明角色武器差异，以及少数能融入关卡设计的冲刺和近战能力，足以支撑一款轻量作品；复杂系统不是乐趣的前提。[Cubed3 评论](https://www.cubed3.com/games/reviews/pc/exo-calibre)
- **Roguelike 构筑能为每轮增加选择。** 《Sektori》（2025）把随机布局、战斗中升级和玩家选择何时触发升级结合起来，让构筑决策直接进入射击节奏。[GameSpot 评论](https://www.gamespot.com/articles/last-years-best-bullet-hell-shooter-is-now-on-switch-2-where-it-always-belonged/1100-6539948/)
- **独特美术和可读性可以一起设计。** 《Platypus Reclayed》（2025）的评论指出，鲜明的手工黏土外观之外，敌人轮廓、弹幕颜色和 HUD 清楚也帮助玩家在屏幕繁忙时判断危险。[Nux Game Guides 评论](https://nuxgameguides.com/reviews/platypus-reclayed-review/)
- **小团队作品可以通过混合节奏做出差异。** 《NEXT JUMP: Shmup Tactics》将射击美学与回合制策略结合，证明“飞机射击”可以探索经典即时射击以外的玩法方向；本企划保留即时操作，避免把首版扩大成策略游戏。[Steam 玩家评论](https://steamcommunity.com/id/wendrex/recommended/624690/)

这些案例不能代表销量或整个市场的排名。本企划采取的方向是：保留一眼能懂的竖版即时射击，借用短局构筑的重玩理由，再用“擦弹充能后折跃反击”作为自己的主要机制。首版优先验证手感、弹幕清晰度和折跃决策，不追逐系统数量。

## 验收目标

- 新玩家在一局内能理解移动、精控、擦弹和折跃。
- 玩家受击时能看出是何种弹幕造成，头目攻击有可辨识的预告与空隙。
- 折跃既能救急也能进攻，玩家会根据局势决定何时使用。
- 至少三种模块组合带来可感知的不同打法。
- 从开始到结算不中断，失败后可在数秒内重开。
